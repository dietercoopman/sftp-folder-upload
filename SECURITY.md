# Security policy

SFTP Folder Upload sends files and credentials to your servers, so security reports get priority.

## Supported versions

Only the latest version on the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=delta-solutions.sftp-folder-upload) receives fixes. VS Code updates extensions automatically, so a fix reaches users quickly.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through [GitHub's private vulnerability reporting](https://github.com/dietercoopman/sftp-folder-upload/security/advisories/new).

Include the version of the extension, your `sftp.json` with credentials removed, and the steps to reproduce. You get a reply within a few working days. Fixed issues are listed in the [changelog](CHANGELOG.md) and credited if you wish.
